# 규칙을 하나씩 지운 사본에서 검사가 실패하는지 확인

묻지 않게 하는 규칙의 검사가 "규칙이 없어도 통과하는" 빈 검사가 아닌지 확인합니다. 규칙 한 줄(또는 한 덩이)을 지운 임시 사본을 만들고 `:engine:test`를 돌려, 그 규칙을 지키는 속성 검사가 실패하면 "잡힘"으로 적습니다.

| 지우는 규칙 | 실패해야 하는 검사(따로 적지 않으면 `SafetyPropertyTest`) |
|---|---|
| 통화·안내 음성 중 | 통화 중이거나 안내 음성이 나오면 다른 값이 무엇이든 말을 걸지 않는다 |
| 확인할 수 없는 안전 신호 | 확인할 수 없는 안전 신호가 하나라도 있으면 완전히 멈춘 때만 묻는다 |
| 멈춘 때 읽지 못한 방향지시등·다음 회전 | `MomentJudgeTest`: 길 안내 중인데 다음 회전 정보가 없으면 멈춰 있어도 묻지 않는다 |
| 회사 가는 길 | 목적지가 회사면 다른 값이 무엇이든 묻지 않는다 |
| 이미 있는 경유지 | 이미 경유지가 있거나 잔량이 기준 아래면 묻지 않는다 |
| 낮은 잔량 | 이미 경유지가 있거나 잔량이 기준 아래면 묻지 않는다 |
| 지나친 찜 | 진행 방향 뒤쪽의 찜은 다른 값이 무엇이든 묻지 않는다 |
| 시속 90km 이상 | 시속 90km 이상이면 다른 값이 무엇이든 묻지 않는다 |
| 판단 반경 밖 | 찜이 판단 반경 2km 밖이면 다른 값이 무엇이든 묻지 않는다 |
| 보류한 사이 반경 이탈 | 보류한 사이 반경을 벗어난 찜은 그 이동에서는 다른 값이 무엇이든 묻지 않는다 |

## 돌리기

저장소 맨 위에서, JDK 17(`JAVA_HOME`)과 Python 3.9 이상이 있으면 됩니다. Android SDK는 필요 없습니다(사본의 `settings.gradle.kts`에서 `:app`을 뺍니다).

```
python docs/rule-removal-check/rule_removal_check.py --jobs 4
python docs/rule-removal-check/rule_removal_check.py --only "지나친 찜"   # 하나만
```

- 먼저 아무것도 지우지 않은 사본이 모두 통과하는지 보고, 통과하지 않으면 멈춥니다.
- 사본은 임시 폴더에 만들고 끝나면 지웁니다. 저장소 파일은 바꾸지 않습니다.
- 지울 줄은 줄 번호가 아니라 글자 그대로 찾습니다. 소스가 바뀌어 찾지 못하면 그 규칙은 "찾지 못함"으로 적고, 종료 코드가 0이 아닙니다.
- 사본 하나에 2분 안팎이 걸립니다(2026-11-14, `--jobs 5`로 기준 포함 10개에 약 6분 반).

마지막으로 돌린 결과는 [`result.txt`](result.txt)에 있습니다.
